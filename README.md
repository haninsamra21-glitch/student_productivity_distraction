# student_productivity_distraction
This project applies Machine Learning techniques to analyze how different factors impact student productivity and distraction levels. The dataset is sourced from Kaggle.

🔍 Objectives
Analyze student behavior and productivity patterns
Identify key factors that lead to distraction
Build a predictive model for student productivity
🧠 Techniques Used
Data Cleaning & Preprocessing
Exploratory Data Analysis (EDA)
Feature Engineering
Machine Learning Models (e.g., Regression / Classification)
📊 Tools & Technologies
Python
Pandas, NumPy
Scikit-learn
Matplotlib / Seaborn
📁 Dataset
Available on Kaggle (Student Productivity & Distraction dataset)
🚀 Outcome

The model helps in understanding the main factors affecting student focus and can be used to improve study habits and productivity.
